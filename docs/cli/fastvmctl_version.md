# FASTVMCTL-VERSION(1)

## NAME

fastvmctl-version - show CLI and daemon versions

## SYNOPSIS

```text
fastvmctl version
```

## DESCRIPTION

Prints the CLI build version and the daemon version reported over the API.

## OPTIONS

No command-specific options.

## EXAMPLES

```sh
fastvmctl version
```
